# ExpenseTracker

Aplicación móvil diseñada para registrar, organizar y mantener el control de los gastos diarios. Este proyecto está siendo desarrollado con React Native y Expo.

## 🚀 Estado del Proyecto: Sprint 1 (Completado)

Durante el primer sprint se establecieron las bases tecnológicas y visuales de la aplicación:

* **Inicialización:** Proyecto creado con Expo (`template blank`) para garantizar un entorno limpio y sin dependencias innecesarias.
* **Arquitectura Escalable:** Implementación de un sistema de carpetas modular (`src/screens`, `src/components`, `src/navigation`, `src/assets`) para facilitar el crecimiento de la app.
* **Pantalla de Bienvenida:** Interfaz inicial (`HomeScreen.js`) construida con Core Components y Flexbox.
* **Formulario de Gastos:** Creación del componente `NewExpenseModal.js` para la captura de datos (Nombre, Monto y Categoría) mediante `TextInput` interactivos y teclado numérico.

## 🛠️ Tecnologías Utilizadas

* **React Native:** Framework principal.
* **Expo / Metro Bundler:** Entorno de desarrollo y compilación.
* **JavaScript / JSX:** Lógica y renderizado de interfaces.

## ⚙️ Cómo levantar el proyecto localmente

Sigue estos pasos para ejecutar la aplicación en tu entorno local:

### 1. Requisitos previos
* Tener instalado [Node.js](https://nodejs.org/).
* Instalar la aplicación **Expo Go** en tu dispositivo físico (disponible en Android e iOS), o tener configurado un emulador.

### 2. Instalación
Clona este repositorio y navega hasta la carpeta del proyecto. Luego, instala las dependencias necesarias:

npm install
  
### 3. Ejecución
npx expo start
